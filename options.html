Sheets Mouse Remover

Excel shortcuts for Google Sheets, by ARC

ASMR

Click a key field, then press the new keys. Letters without a modifier build a sequence (finish with Enter). A press with Ctrl, Cmd or Option, or a function key, is saved as a direct shortcut. Esc cancels, Backspace removes the last letter.
Custom menu path: the menu labels separated by >, for example Data > Create a filter. A label only has to match the start of the menu entry.
